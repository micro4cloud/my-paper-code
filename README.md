# ML-V2LC-CM: Hybrid Machine Learning Framework for Vehicular VLC

## Overview
This project implements a hybrid machine learning framework for Vehicular Visible Light Communication (V2LC) channel modeling.

## Features
- Hybrid deep learning model (DNN + LSTM ready)
- RMSE, MAE, R² evaluation
- PyTorch implementation
- Real-time prediction capable

## Dataset Format
NPZ file:
- features: input matrix
- labels: target values
